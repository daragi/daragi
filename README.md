- **Focus** — Product Analytics · Business Intelligence · Customer/Operations Analytics
- **Strength** — 데이터 전처리부터 KPI 설계, 시각화, 액션 제안까지 분석 전 과정을 연결합니다.

## Analytics workflow

| Step | Question | Deliverable |
| :---: | :--- | :--- |
| **01. Define** | 어떤 비즈니스 문제를 해결할 것인가? | 문제 정의 · 가설 · 성공 지표 |
| **02. Prepare** | 데이터가 분석 가능한 품질인가? | 데이터 모델 · 전처리 · 품질 검증 |
| **03. Analyze** | 지표 변화의 원인과 병목은 무엇인가? | EDA · 세그먼트 · 퍼널/코호트 |
| **04. Communicate** | 누가 무엇을 결정해야 하는가? | 대시보드 · 핵심 인사이트 |
| **05. Act** | 어떤 액션을 어떻게 검증할 것인가? | 우선순위 · 실험안 · 후속 KPI |
